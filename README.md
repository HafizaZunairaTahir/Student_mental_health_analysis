# 🧠 Student Mental Health: The "Triple Threat" Analysis

## 📌 Executive Summary
As a 15-year-old **Hafiza**, **Martial Artist**, and **Aspiring AI Founder**, I believe data is the ultimate tool for solving human crises. This project is a multivariate investigation into university student wellness, specifically uncovering the **"Triple Threat"**—the critical intersection where Depression, Anxiety, and Panic Attacks overlap.

## 🚀 Key Discoveries
* **The 9.9% Crisis:** Data analysis revealed that nearly 1 in 10 students suffer from all three conditions simultaneously.
* **The Topper’s Tax:** Identified a significant correlation between high academic performance (CGPA 3.5+) and increased anxiety levels.
* **Actionable Insights:** Proposed four data-driven wellness strategies to bridge the gap in professional help-seeking behavior.

## 🛠️ Technical Implementation
Using a **Topper mindset** of precision and grit, I utilized **Python** to transform raw survey data into actionable insights:
1.  **Cleaning:** Standardized inconsistent responses using **Pandas**.
2.  **Analysis:** Performed multivariate correlation to find hidden patterns in student behavior.
3.  **Visualization:** Created high-impact heatmaps and interactive charts using **Seaborn** and **Plotly**.

## 📂 Tech Stack
* **Languages:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Plotly
* **Environment:** VS Code, Conda, Kaggle
